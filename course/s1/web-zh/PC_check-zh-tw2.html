🖥️ 電腦安全指南

檢查您的電腦是否中毒及後續處理動作

本單元專為非技術背景的用戶設計，協助識別、控制及從潛在的電腦感染或駭客攻擊中復原。科技有時可能令人困惑，但保護您的資料其實並不困難。

您將學到什麼：

  • 如何分辨真正的電腦病毒和「假」詐騙彈出視窗。
  • 如果您認為自己被駭客入侵，應立即採取什麼行動。
  • 如何保護您的帳戶並防止未來的攻擊。

點擊上方選單的 「1. 中毒跡象」 開始學習。

步驟 1：中毒跡象

並非每個電腦故障都是駭客攻擊。學會區分真正的威脅與常見的干擾。

⚠️ 常見詐騙：「瀏覽器通知」

情況： 即使關閉了瀏覽器，您仍會在螢幕角落看到寫著「系統已感染」或「McAfee已過期」的彈出視窗。

真相： 這幾乎不可能是病毒。您很可能是不小心在某個可疑網站上點選了「允許通知」。

解決方法： 前往瀏覽器設定 > 隱私權和安全性 > 網站設定 > 通知。移除可疑的網站。

💡 終極手段： 如果找不到有問題的網站太麻煩，請前往瀏覽器設定並搜尋「重設」。這會將設定恢復為預設值，停用煩人的擴充功能並清除不良權限，且完全不會刪除您儲存的密碼或書籤。

真正的危險信號

  • 異常緩慢： 在您甚麼都沒做的時候，電腦風扇聲音依然非常大。
  • 新的擴充功能： 瀏覽器出現您未曾安裝的工具列或預設搜尋引擎。
  • 滑鼠游標自行移動： 在您未觸碰的情況下自行移動（這需要立即拔除網路線！）。
  • 帳戶警告： 收到電子郵件提示「來自某某國家的新登入」，而那不是您本人。

如何安全地檢查

1. Windows 用戶

「快速掃描」雖然不錯，但有時惡意軟體會在 Windows 運行時隱藏自己。請改用 Microsoft Defender 離線掃描。

開啟 Windows 安全性 > 病毒與威脅防護 > 掃描選項 > 選擇 Microsoft Defender 離線掃描。這會重新啟動您的電腦，並在 Windows 完全載入*之前*進行掃描，從而徹底阻止頑固的病毒。

2. macOS (蘋果電腦) 用戶

您的 Mac 有一個名為 XProtect 的隱形防護機制會自動運行。您無法手動「開啟」它。如需手動檢查，請下載免費版的 Malwarebytes for Mac 來安全地掃描您的系統。

步驟 2：立即處置

如果您確認存在威脅，請迅速行動。最重要的是，不要驚慌。

1. 立即斷網

拔掉網路線或關閉 Wi-Fi。這是絕對最好的第一步。它能在實體上阻止惡意軟體將您的私人數據傳送給駭客，或是防止它繼續下載勒索軟體。

2. 「全螢幕」詐騙凍結

如果您的瀏覽器突然卡住，發出巨大的警報聲，並出現一個紅色大螢幕要求您撥打「微軟/蘋果支援中心」，請絕對不要撥打該號碼。這只是一個試圖恐嚇您的網頁腳本，並不是真正的駭客入侵。

解決方法： 強制關閉瀏覽器。

  • Windows： 按 Alt + F4，或使用 Ctrl+Shift+Esc 開啟「工作管理員」並結束該應用程式。
  • Mac： 按 Cmd + Option + Esc 選擇「強制結束」。

3. 安全模式

在安全模式下重新啟動只會載入基本檔案，能防止病毒運行。

  • Windows： 按住 Shift 鍵的同時點擊「重新啟動」 > 疑難排解 > 進階選項 > 啟動設定。
  • Mac（Intel 處理器）： 關機，再次開機，並立即按住 Shift 鍵，直到看到登入視窗。
  • Mac（Apple 晶片 M1/M2/M3/M4 等）： 關機。按住電源按鈕直到看到「載入啟動選項」。選擇您的主磁碟，按住 Shift 鍵，然後點擊「以安全模式繼續」。

步驟 3：復原與預防

一旦威脅被移除，您必須保護您的資料以防止未來的攻擊。

1. 雙重認證 (2FA) - 關鍵設定

現在光靠密碼已經不足以保護您。您必須為您的電子郵件和財務帳戶開啟雙重認證（有時稱為 MFA 或兩步驟驗證）。

這需要第二個步驟來登入——例如傳送到您手機的簡訊代碼或身分驗證器 App (Authenticator)。即使駭客猜出了您的密碼，如果沒有您的實體手機，他們也無法進入您的帳戶。

2. 密碼安全與登出

使用值得信賴的密碼管理工具（如 Bitwarden、1Password，或內建的 Apple/Google 密碼管理員）為每個網站生成獨立的密碼。請避免在不同網站重複使用相同的密碼。

重要提示： 更改密碼並不一定能立即將駭客踢出。請務必在您的帳戶安全設定中尋找並點擊 「登出所有裝置」 或「撤銷所有使用中的工作階段」的按鈕。

3. 我的密碼外洩了嗎 (Have I Been Pwned?)

大多數的「被駭」事件發生，是因為您多年前購物過的公司發生了資料外洩。要檢查您的密碼是否曾在網路上洩露，請瀏覽安全且免費的網站 haveibeenpwned.com。輸入您的電子郵件；如果畫面顯示為紅色，請立即更改那些受影響網站的密碼。

4. 檢查電子郵件轉寄規則

駭客經常在您的信箱設置隱藏的「規則」，將您收到的電子郵件（尤其是密碼重設信）自動轉寄給他們。請前往您的電子郵件設定 > 轉寄和 POP/IMAP（或篩選器），並刪除任何不是您親自建立的規則。

5. 使用離線備份擊敗勒索軟體

如果您的檔案被加密（中了勒索軟體），請絕對不要支付贖金。這只會資助犯罪分子，而且完全不能保證能找回檔案。擊敗勒索軟體的唯一真正方法是擁有離線備份。

購買一個外接 USB 硬碟，備份您的重要文件，最重要的是——備份完成後請務必拔掉硬碟。如果硬碟一直插在電腦上，病毒也會連同您的備份硬碟一起加密感染。
