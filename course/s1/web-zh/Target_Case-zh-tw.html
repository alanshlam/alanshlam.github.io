EDU Target 案例

2013 年 Target 資料外洩事件

一個關於史上最大零售業網路攻擊之一的互動課程。

4000萬張信用卡被盜。7000萬人受影響。


🔍 發生了什麼？

駭客透過一家第三方暖通空調供應商滲透 Target 的網路，並直接從收銀機竊取信用卡資料。

🛡️ 為何要學習此案例？

此案例改變了我們使用信用卡的方式（晶片和密碼），並讓全世界了解到「第三方風險」是一個主要危險。

攻擊時間軸

2013年11月中

最薄弱的一環

駭客向 Fazio Mechanical Services（暖通空調供應商）發送釣魚郵件。利用 Citadel 惡意軟體，他們竊取了 Target 供應商入口網站的登入憑證。

2013年11月15日至27日

橫向移動

攻擊者存取供應商入口網站。由於網路是「扁平的」（未分段），他們使用「傳遞雜湊」從供應商區域跳到敏感的銷售點 (POS) 網路。

2013年11月27日至12月15日

RAM 抓取

惡意軟體 (Kaptoxa/BlackPOS) 被安裝在收銀機上。它在刷卡瞬間從系統記憶體 (RAM) 中讀取信用卡號碼。

2013年12月19日

揭露

在信用卡公司和記者的警報後，Target 確認了外洩事件。4000萬張卡和7000萬筆個人記錄消失。執行長最終辭職。

技術剖析

1. 供應鏈攻擊

Target 有堅固的城牆，但他們給了一把鑰匙給一個安全性薄弱的供應商（暖通空調）。攻擊者入侵該供應商，從而大搖大擺地走進前門。

2. 網路分段

失敗之處：暖通空調系統和信用卡系統在同一個網路上。
解決方案：「零信任」架構。將關鍵系統分開，這樣一個系統淪陷，另一個仍然安全。

3. RAM 抓取

PCI-DSS (Payment Card Industry Data Security Standard) 法規規定不能將信用卡號碼儲存在磁碟上。但電腦必須讀取號碼才能收費。攻擊者編寫了一個腳本，在那個1秒的處理視窗期間從電腦的暫存記憶體 (RAM) 中讀取資料。

消費者防禦：如何保護自己

您無法阻止一家公司被駭，但您可以限制您的損失。以下是從 Target 案例中學到的 4 條黃金法則。

💳

規則一：信用卡優於簽帳卡

如果駭客偷了您的簽帳卡，他們會花掉您的真實現金。如果他們偷了您的信用卡，他們偷的是銀行的錢。您有 0 元責任保護，您的支票帳戶仍然安全。

❄️

規則二：信用凍結

Target 外洩事件也洩漏了姓名和地址。罪犯可以用這些資料以您的名義開設新的信用卡。一個免費的信用凍結（在 Equifax、Experian、TransUnion）讓任何人都無法以您的名義開設帳戶。

📲

規則三：行動錢包（代碼化）

當您使用 Apple Pay 或 Google Pay 時，您的手機會向店家傳送一個隨機的「代碼」，而不是您的真實卡號。即使 Target 再次被駭，駭客也只會得到一個無用的一次性代碼。

👀

規則四：每週監控

不要等待郵件通知。在您的手機上為任何超過 1 美元的消費設定交易提醒。您越快報告詐欺，解決起來就越容易。
