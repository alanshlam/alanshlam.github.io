第二集：雲端安全

1. 故事背景

故事來自 HKCERT 動畫影片

阿進經營一家零售公司。他因為自建的伺服器過於老舊而被駭。一位資安顧問建議他遷移到雲端。然而，他差點再次被駭，因為他以為「雲端」就等於「自動安全」。

2. 陷阱

🔓
設定不當 (Misconfiguration)

阿進把客戶資料放在雲端，但沒有設定密碼或權限。這就像離開家時沒鎖門一樣。

💡 教訓：放在雲端不代表就已上鎖。

3. 誰該做什麼？

🤝
共同責任模型
  • 供應商的工作：修復硬體、電力和網路線。
  • 您的工作：設定密碼、管理誰有存取權限以及加密檔案。

4. 確保安全的 5 個步驟

  1. 閱讀手冊：查看設定指南。
  2. 進行測試：驗證您的安全設定是否有效。
  3. 檢查日誌：尋找可疑的活動記錄。
  4. 多重驗證與加密：使用多重要素驗證並加密檔案。
  5. 備份：永遠保留一份您的資料副本。
