桌面安全基礎

保護電腦是一個生命週期過程。學習在不影響電腦可用性的情況下保護您的資料。

🛡️ 預防
🔄 復原
👁️ 偵測

🏗️ 設定

基礎所在。安裝作業系統、啟用加密並採用通行密鑰 (Passkeys)（密碼的繼任者）。

🔧 維護

日常工作。更新、DNS 過濾和稽核可確保新的漏洞不會危害您的系統。

⚔️ 防禦工具

從適合家庭使用者的簡單內建智慧防毒軟體，到適合企業的進階 24/7 MDR 威脅狩獵。

初始設定：基礎

💿 作業系統與加密

  • 從乾淨的作業系統安裝開始。
  • 啟用全磁碟加密（Windows 的 BitLocker / Mac 的 FileVault）。
  • 建立一個獨立的標準使用者帳戶進行日常網頁瀏覽。

🔑 通行密鑰與身分驗證

  • 採用通行密鑰： 使用生物辨識（FaceID/指紋）代替輸入密碼。
  • 密碼管理員： 對於較舊的網站，請使用密碼管理員（如 Bitwarden）。
  • 多重身分驗證 (MFA)： 使用驗證器應用程式，絕對不要使用 SMS 簡訊。

☁️ 備份：「不可變」規則

3 份資料副本。

2 種不同的媒體類型。

1 份副本是不可變/離線的。

*關鍵：勒索軟體會破壞連線的 USB/雲端備份。您需要一份駭客絕對無法刪除的副本。

持續維護：保持安全

🔄 更新與修補程式

每天都會發現新的軟體漏洞。將作業系統、瀏覽器和應用程式設定為自動更新。

盲點： 不要忘記偶爾檢查韌體 (BIOS) 和硬體驅動程式更新。

🎓 人類防火牆

如果人類受騙，技術就會失效。當心人工智慧網路釣魚 (AI Phishing)：使用人工智慧產生的電子郵件聽起來非常專業，消除了我們過去用來識別騙局的常見錯字。

📋 稽核與還原

定期檢查您的線上登入活動。更重要的是，測試您的備份！ 一個您從未成功測試還原的備份只是一種希望，而不是實際的策略。

防禦工具：從家庭到企業

安全軟體的需求取決於您是在保護個人筆記型電腦還是整個公司網路，兩者有著巨大的差異。

第 1 部分：「門外漢」解決方案（家庭使用者）

對於個人而言，目標是「設定後就忘記它」。您需要的是能在背景安靜運作，且不會要求您分析複雜安全警報的保護。

🛡️ 內建「智慧」防毒

使用什麼： Windows 安全性 (Defender) 或 Mac XProtect。

現代內建安全功能非常出色。它包含基本的行為監控，並在背景免費自動阻擋威脅。（現在很少需要手動完整掃描；確保「即時保護」保持開啟）。

🦠 消費者「次世代」防毒

使用什麼： Malwarebytes Premium 或 Bitdefender。

如果您需要額外保護，這些軟體運作起來像企業工具，但具有簡單的介面。它們不會向您展示病毒如何運作的複雜圖表，而是簡單地彈出並說：「我們封鎖了惡意行為。您很安全。」

🌐 自動 DNS 過濾

使用什麼： Quad9 (9.9.9.9) 或 NextDNS。

將此視為網際網路的安全電話簿。在您的電腦連接到不良網站之前，它會自動封鎖惡意連結。它靜默運作，且需要零維護。

⚠️ 您是家庭使用者嗎？

如果您正在保護個人電腦，您不需要下面提到的 EDR 或 MDR 工具。 堅持使用第 1 部分中的解決方案即可。以下部分僅用於幫助您了解小型企業和公司如何保護其網路！

第 2 部分：進階安全（企業版 EDR 與 MDR）

為什麼企業要花費數千美元購買 EDR 和 MDR 等複雜工具？讓我們用家庭保全的類比來解釋它們與一般防毒軟體有何不同。

1. 傳統防毒 = 「通緝」海報

保鑣站在您家前門，看著已知罪犯的清單（已知病毒特徵碼）。如果清單上的人試圖進入，他們就會被擋下。

缺點：如果罪犯偽裝自己（一種全新的、未知的病毒），保鑣就會讓他們直接進入。

2. EDR = 智慧攝影機與感測器

端點偵測與回應 (Endpoint Detection & Response)

EDR 假設壞人已經通過了前門。它觀察行為。如果客人進來後立即試圖撬開保險箱的鎖，系統就會放下金屬條封鎖門以困住他們（網路隔離）。

缺點： 它過於敏感。每次您的貓走過感測器時，它都會發出警報，導致 IT 人員產生「警報疲勞」。

3. MDR = 24/7 警衛

託管偵測與回應 (Managed Detection & Response)

因為 EDR 產生太多警報，企業會聘請外部安全公司（如 ADT）為他們監控攝影機。

優點： 當感測器響起時，安全專家會去查看。如果是貓，他們會清除警報。如果是竊賊，他們會阻止它。他們只在真正發生火災時才會打電話給企業主。

情境很重要：個人與中小企業 (SME)

雖然技術基礎相同，但家庭使用者和企業之間的規模和責任差異很大。

安全功能 個人 / 家庭使用者 中小企業 (SME)
存取控制 個人帳戶 最小權限（員工沒有管理員權限）
防禦工具 內建智慧防毒（免費） MDR（託管服務團隊）
網路 家庭 ISP 路由器 DNS 過濾與網路分段
更新 自動 集中管理與測試（修補程式管理）
理念 「上網小心」 零信任（驗證每個請求，不自動信任任何人）
