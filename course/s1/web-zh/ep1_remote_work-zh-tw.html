第一集：線上會議安全

1. 問題所在

故事來自 HKCERT 動畫影片

阿俊的員工正在家工作 (WFH)。駭客強哥對此感到興奮，因為家用電腦通常缺乏公司級別的安全性，這讓他更容易竊取商業機密。

2. 咖啡店陷阱

☕
假 Wi-Fi (邪惡雙胞胎)

駭客會建立假的 Wi-Fi 熱點（例如「免費咖啡店 Wi-Fi」）來攔截您的資料。如果您連線，他們就可以複製您的檔案。

🛡️ 現代提示：不要使用公共 Wi-Fi 工作。改為開啟您手機的 4G/5G 熱點。這樣安全得多！

3. 安全通道 (VPN)

🚇
虛擬私人網路

VPN 就像一條在您家和辦公室之間的安全、加密的通道。它能阻止駭客窺探您在網路上傳送的內容。

⚠️ 警告：如果您的家用電腦有病毒，VPN 可能會將該病毒帶到辦公室！請確保您家中的防毒軟體已更新。

4. 安全的視訊會議

📹
防止「會議轟炸」

駭客喜歡闖入會議。為了安全起見：

  • 為每次會議使用唯一的會議 ID 和密碼。
  • 開啟等候室功能以驗證與會者。
  • 一旦所有人都加入後，鎖定會議。
  • 定期更新軟體。

5. 最後一道防線

🔐
加密

在影片中，駭客偷了一個檔案但無法打開，因為它被加密了。

💡 教訓：務必加密敏感檔案。即使 USB 隨身碟遺失或駭客偷了檔案，資料對他們來說仍然是無法讀取的亂碼。
