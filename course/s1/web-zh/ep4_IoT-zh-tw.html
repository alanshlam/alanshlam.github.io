第四集：物聯網安全

1. 情境

故事來自 HKCERT 動畫影片

阿俊有一個高科技的家，裡面有由 5G 控制的智慧窗簾、電飯煲和網路攝影機。駭客（強哥）試圖侵入這些設備來監視他和竊取資料。

2. 什麼是物聯網？

🌐
物聯網 (Internet of Things)

物聯網指的是日常物品（攝影機、冰箱、感應器）連接到網際網路。借助 5G，我們可以高速連接數百萬台設備。

⚠️ 風險：駭客使用「殭屍網路」(Botnets)。他們感染數千個脆弱的物聯網設備，並利用它們來攻擊其他目標。

3. 陷阱：「隨插即用」

🔓
預設密碼

阿俊插入他的設備後立即使用，沒有更改任何設定。駭客使用「暴力破解」工具輕鬆猜出了密碼。

為什麼？因為許多設備出廠時都帶有像 admin / admin 或 123456 這樣的預設密碼。

4. 解決方案

要保護您的智慧家庭，請遵循以下 4 個規則：

  • 更改預設密碼：絕對不要使用出廠密碼。建立一個強大且獨特的密碼。
  • 更新韌體：就像您的手機需要 iOS/Android 更新一樣，您的網路攝影機也需要「韌體」更新來修補安全漏洞。
  • 使用 WPA2/WPA3：確保您的 Wi-Fi 路由器使用這些加密標準。
  • 網路分割（專業提示）：將智慧設備放在「訪客網路」上，這樣它們就與您的筆記型電腦/銀行資料分開。
