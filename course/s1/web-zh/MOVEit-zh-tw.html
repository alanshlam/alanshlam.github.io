MOVEit Transfer 漏洞 (2023)

這起駭客事件竊取了 9300 萬人的資料，而他們甚至從未聽說過「MOVEit」。

🕷️ 供應鏈

您沒有使用 MOVEit。但您的航空公司（英國航空）、您的政府（能源部）和您的薪資服務供應商都在使用。當他們被駭時，您的資料就被竊取了。

☠️ 駭客：Cl0p

一個與俄羅斯有關的勒索軟體組織。他們不鎖電腦，只竊取資料並威脅在暗網上洩露（勒索）。

🔓 漏洞：SQL 注入

一個「零時差」漏洞允許駭客向資料庫發送特殊命令，完全繞過密碼。

無聲的竊盜時間軸

2023年5月下旬

秘密利用

Cl0p 駭客發現 MOVEit Transfer 中的一個零時差漏洞。他們悄悄地掃描網際網路並在任何人知道軟體有問題之前竊取資料。

2023年5月31日

公開披露

Progress Software 宣布了這個錯誤並發布了補丁。但對許多人來說為時已晚。資料在幾天前就已被盜。

2023年6月

洩漏開始

Cl0p 在其暗網網站上列出受害者名單。英國航空、BBC 和殼牌公司都被點名。他們要求贖金以保護資料隱私。

2023年底 - 2025年

後續影響

超過 9300 萬人面臨身份盜竊風險。集體訴訟被提起。各國政府對軟體責任展開調查。

技術剖析

1. SQL 注入 (SQLi)

網站介面未正確檢查使用者輸入。駭客在登入欄位中輸入命令，欺騙資料庫給予他們「系統管理員」權限。

2. 網站後門 (Web Shells)

進入後，駭客安裝了一個名為 human2.aspx 的後門。這讓他們可以隨意進出，隨時竊取檔案。

3. 零時差漏洞利用

這表示該漏洞對軟體製造商來說是未知的。攻擊開始時沒有可用的補丁。

消費者防禦：當「他們」被駭時

您無法修補英國航空的伺服器。但您可以保護自己免受其後續影響。

❄️

1. 凍結您的信用

這是第一道防線。由於社會安全碼和薪資資料被盜，罪犯可以用您的名義申請貸款。信用凍結（Equifax、Experian、TransUnion）可以徹底阻止他們。

🔎

2. 「Have I Been Pwned?」

使用像 Have I Been Pwned? 或 Mozilla Monitor 這樣的網站。輸入您的電子郵件，查看您的資料是否在 MOVEit 漏洞中洩漏。知識就是力量。

🎣

3. 預期針對性釣魚

詐騙者現在知道您的姓名、地址以及您在哪家銀行開戶。他們會發送令人信服的電子郵件，冒充這些公司。獨立驗證每個請求。

🔑

4. 到處使用 MFA

如果您的密碼是洩漏的一部分，駭客會嘗試用它登入您的電子郵件和銀行。多重身份驗證 (MFA) 即使他們有您的密碼也能阻止他們。
