How to Update

Where to find the "Auto-Update" button on your devices.

🍎
iPhone / iPad
Settings > General > Software Update > Automatic Updates > ON
🤖
Android
Settings > System > System Update. (Varies by phone).
🪟
Windows
Start > Settings > Update & Security > Windows Update.
🍏
Mac
System Settings > General > Software Update > Automatic Updates.
